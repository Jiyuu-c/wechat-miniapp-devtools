# Open-source basis

This project uses the following external components:

- `@creatoria/miniapp-mcp@0.2.3`, an MCP server for WeChat Mini Program automation.
- WeChat's official `miniprogram-automator` automation SDK through the MCP server.
- WeChat DevTools CLI for opening projects and enabling automation.

The repository contains wrappers, configuration templates, Agent workflow guidance, and recovery rules. It does not redistribute WeChat DevTools or the external package source.

Review upstream licenses and release notes before upgrading dependencies.
